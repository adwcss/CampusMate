# 晴空物语 · 河职大 3D 校园

从项目根目录运行 `python run.py`，打开 http://127.0.0.1:8765/campus3d/ 。原有「校园地图」页已增加入口。渲染库保存在本地，页面运行无需 CDN、API 密钥或前端构建。

功能：真实 WebGL 三维场景、建筑点击选取、旋转缩放和平移、俯视切换、标签开关、30 个地点的搜索与分类、建筑详情、宿舍参考照片、响应式布局与来源说明。

布局基于项目内校园地图和「校园地图.md」；官网用于核查地标类型和资料可得性。当前只覆盖参考图范围，未取得完整新校区测绘和建筑图纸。体量、高度、窗户、立面、树木和入口均为美术示意，不能用于实际导航。坐标为原图相对坐标，不是经纬度。

室内规则：仅对宿舍提供现有照片和俯视参考；没有证据表明这些照片对应某栋楼。没有取得整栋楼逐层资料，故不开放真实室内漫游。后续有授权楼层平面图或全景资料后，可按建筑 ID 增补，不能把推测房间当成真实校园。

主要公开来源（核查日期：2026-11-05）：
- https://www.hnvust.cn/xxgk/xyfg.htm
- https://www.hnvust.cn/xysh/xydt.htm
- https://www.hnvust.cn/xxgk/xnxy.htm

数据更新：修改「校园地图.md」后运行 `python tools/build_campus3d_data.py`。场景代码的建筑细部属于风格化模型。

验证：`node tools/verify_campus3d.mjs` 使用已有 Playwright 与 Edge，自动启动隔离测试服务，检查三维渲染、真实射线选取、搜索分类、照片切换、视角控件、对话框及手机布局。截图与结果写入 `output/campus3d/`。
