# 用户地图美化与接入

本次以用户在聊天中提供的813×792像素地图为依据，替换2.0版本的泛化SVG插画。原图保留于`frontend/assets/maps/hnvust-map-original.png`；正式美化地图为`hnvust-map-beautified.svg`，内嵌AI绘制底图与可编辑的两处宿舍编号文字层。这是用户提供示意图的视觉整理，未声明为经学校认证的官方测绘成果。

处理重点：原有建筑布局与主路位置、图面色彩和文字可读性、去除黑色定位图钉、保留原图随时对照。使用内置图像编辑工具，未调用项目中的AI密钥或搜索密钥。生成图中的微小文字仍可能出现偏差，页面保留明显提示与原图对照按钮，业务事实以原资料及现场为准。

旧版根据另一张图标注的百分比与用户图不一致，因此新增`config/map-user-alignment.json`记录本次逐点取样。原图上可辨认的30个地点参与地图显示；未清晰确认的旧地点保留ID和历史说明，撤下定位点，不影响已保存行程的读取。地图文字知识同步更新，旧知识文件保存在`docs/校园地图-旧坐标历史.md`。湖名依旧为历史称呼，新图仅能确认水面形状，已在说明中区别。

交互变化：默认展示不被数字遮挡的地图；勾选“显示地点标记”后再显示图钉，单点选择可单独显示；保留名称搜索、区域筛选、缩放、完整大图和个人行程。“对照上传原图”切换地图、热点坐标与行程线。未确认地点不进入新预设行程，也不会用线段越过缺失点连接。

原图、美化图、生成说明和文件校验值均随项目保存。之前的原始地图图片与历史发布ZIP没有删除。本次检查纠正了AI初稿把北侧餐厅写成第一餐厅、把图书馆写成网球馆等错误；并依据原图将绿色园区标为百草园，不延用旧版“网球场”的解释。图像工具最后一轮仍未交换两处宿舍数字，因此正式地图用SVG文字层明确校正；未把含错号的AI底图单独作为成品。底图`hnvust-map-artwork.png`仅作素材，实际页面使用完整SVG。没有用Python或其他工具重绘、修改光栅底图。

本轮自动验收：82项原有回归、24项多高校与地图回归、10项外观状态回归，共116项通过。真实执行输出见`campusmate-verification.json`。提示词完整保存在`map-edit-prompts.json`，文件校验与处理说明见`map-asset-provenance.json`。
