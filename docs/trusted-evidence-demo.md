# 可信问答与双校演示

在仓库根目录运行 `python -X utf8 -S run.py`，打开 http://127.0.0.1:8765/。使用本地知识库可完成演示的前三步。

| 步骤 | 操作 | 观察 |
| --- | --- | --- |
| 1 | 选择河南科技职业大学，问「2026年新生收费标准怎么查？」 | 展开财务处公示引用，核对发布日期、届别和原文附件。缴费流程另查当届通知。 |
| 2 | 提问「2026级报到时间是几号？」；再用首页的外地新生体验题 | 第一问显示待核实；体验题仍可按旧版流程查看历史参考和选择个人准备事项。 |
| 3 | 在河职大新增一条个人任务，切换河南科技大学，问「2026级新生报到和接站怎么安排？」 | 河科大引用本校迎新报道；历史与任务隔离。地图页可打开该校官网原图。 |
| 4 | 选择联网增强，查询「2026级新生绿色通道报到与缓缴怎么申请？」 | 本地摘要引用官方绿色通道通知，联网来源标明正文或原文入口。 |
| 5 | 关闭联网后重启，保持联网增强并重复查询 | 显示回退提示并使用本校本地资料。 |

## 检索与引用

增强模式并行执行本地 BM25 与联网检索。默认按学校配置读取官方栏目；也可用独立 Brave Search API 定位本校公告。读取正文前校验学校域名及公告路径、检查 robots.txt，并拒绝重定向。当前正文提取适配 HTML 公告；图片、附件、PDF 和其他页面布局可能只保留链接。出处包括学校 ID、稳定来源 ID、URL、适用年份、发布日期与检索时间。官网正文标识表示已读取对应网页正文，办理细节仍应核对原文。

本地与联网证据的年份、日期或金额差异由规则提示，页面保留对应来源。开启 DeepSeek 后，增强模式只将核验过的相关证据交给模型，校验每段引文和可见数字。涉及具体报到、接站、军训安排，或模型失败及引用校验失败时，返回证据摘录与核对入口。配置方法见 [README](../README.md)。

## 接入另一所学校

参照 `config/schools/haust.json` 和 `knowledge/haust/sources.json`。使用独立 ID、官方域名、栏目和知识目录。在配置中提供有来源说明的 `places` 后可生成本校示意图。每校使用独立 SQLite 文件和浏览器会话键；河南科技职业大学沿用已有浏览器键。已有宿舍图、三维校园及演练仍由河职大配置控制。

## 验证

两校各项资料的适用范围、待核实事项、接手比对与实际官网结果见 [入学资料核对](arrival-source-audit.md)。

运行 `python -X utf8 -I -S tools/verify.py` 和 `python -X utf8 -I -S tools/verify_multi.py`。后者使用临时数据库验证双校 HTTP 隔离，并用模拟官网、Brave 与 DeepSeek 响应覆盖正文、引用与回退。现场联网效果依赖站点访问、页面结构与服务密钥。
