# 初到：河南科技职业大学新生指南

通过情景演练理解报到、编排校园探索行程，再查资料和完成准备。默认全程使用本地资料，无需 API 密钥、模型下载或第三方依赖。

## 两分钟启动

当前交付版本为1.6.0。需要 Python 3.10 或更新版本，以及现代浏览器。Windows可双击“启动新生指南.cmd”；也可在项目根目录运行：

```powershell
python -X utf8 -S run.py
```

打开 **http://127.0.0.1:8765/**。终端显示“外部模型请求：关闭”即为默认模式。按 Ctrl+C 停止。端口占用时用 `python -X utf8 -S run.py --port 8766`。

不需要 pip install、HuggingFace 下载、入库操作或 D 盘固定路径。前后端由同一个进程提供服务。`-S` 禁用本机额外 site 初始化，避免依赖其他项目的 Python 环境。

## 校园视觉整合（当前工作版本）

蓝、白和浅蓝构成页面主色，红色用于桥形、飘带及小面积强调。波纹、飞鸟和桥线融入标题与背景，导航、按钮和深色模式沿用同一套配色。人物插图按功能搭配：出发准备拉行李、地图指路、成长计划坐姿阅读、问答思考、社团庆祝；标题和正文虚影随页面变化。日常页面不展示角色选择器。

开场固定为统一的学校形象描线显色场景，标签页首次进入默认播放，约3.6秒，可按Esc或点击跳过；同页刷新、切换功能不重播。“外观”提供显示模式、自选背景及“重播开场动画”。遵循系统减少动态效果，旧角色选择不再控制开场。个人图片仍保存在当前浏览器。

[本轮变更与验证](docs/校园视觉整合.md)。此前1.6.0的14款素材已分配到功能页、背景和统一开场，来源记录保留；页面插图访问时才加载。旧交付ZIP/PDF属于之前的界面版本，本轮未重新发布压缩包。[旧版形象与开场记录](docs/校园形象与开场-1.6.0.md)中的素材选择操作仅适用于旧版。

## 1.3.0新增：先演练，再探索

- 新生情景演练：出发前、报到当天、入校后共9个场景，选择后给出解释、建议和可展开的原文依据。
- 记录最近一次选择，显示待复习场景；刷新保留进度和当前场景。练习不自动勾选报到准备，不代表完成注册。
- 校园探索行程：从45个图上地点选择最多8个，提供生活服务、学习空间、课后探索3条参考行程。
- 地图显示探索顺序连线，支持上下移、移除、到访勾选、只看行程及TXT导出。连线不是可通行道路或最短路，没有GPS定位。
- 行程与演练保存到本机SQLite，按浏览器会话隔离；多页面同时操作时检测版本冲突，避免覆盖已有进度。

详情及可复现演示见[1.3.0功能与验收](docs/功能优化与验收-1.3.0.md)。旧版问答、成长计划、日程任务等功能继续保留，可通过导航直达。

## 1.2.0新增：让计划持续用起来

- 日程与任务：最多100项个人任务（含归档），填写自己的日期、优先级与备注，支持进行中、完成和归档恢复。
- 将收藏选项的3条下一步建议生成待办；再次生成会跳过已有建议，保留原进度。
- 未来7天日程、过计划日提示、未排期、进度和关键词筛选；任务筛选随URL保存。
- 导出全天日历`.ics`，由使用者导入日历应用。网页本身只显示提示，没有后台通知。
- JSON任务备份，先校验、预览再合并；相同任务跳过，现有日期与进度保留。只恢复任务，不恢复问答、偏好或清单。
- 资料不足时提供公开通知核对入口，点击后才打开外部网站；搜索使用固定主题词，完整问题不会发送到搜索引擎。

这份附件新增的自动百度/必应抓取已替换为主动核对入口，运行无需Playwright，也不会把搜索摘要当作事实或自动搜索用户问题。详情见[1.2.0功能与验收](docs/功能优化与验收-1.2.0.md)。

## 功能

- 19 份资料、235 个文本块的本地 BM25 检索；来源和年份随每个文本块保留。
- 常见问题、自定义问题与基于用户前文的简短追问；逐段响应和可展开引用。
- 资料不足、年份不明、收费金额与开放时间未知时给出明确提示。
- 新版校园地图45个地点、区域筛选、名称搜索、缩放与大图；逐地点来源和问答保持一致。
- 原作者提供的宿舍、竞赛、社团、学生组织模块：10个床位参考、去重后的67个竞赛、16个社团与14个组织示例。
- 我的成长计划：9个兴趣方向、专业方向和课外时间偏好；4个宿舍位置因素可调权重，显示匹配理由与取舍。
- 同类最多3项对比；最多30项收藏，保存了解进度与下一步建议，刷新继续，随JSON一起导出。
- 11 项报到准备建议，勾选状态写入本地 SQLite；刷新后可继续。
- 对话保存、有帮助/需要改进反馈、JSON 导出、清单打印、桌面深色主题、手机布局。

本地模式按检索资料摘录回答，不冒充大模型生成。其目的是让评委和开发者无需付费额度即可验证完整产品流程。

## API 与密钥保护

已在交接原包 `backend/.env` 和赛事文本中定位同一个密钥。工作副本未复制该 `.env`，只保存了用于拒绝调用的 SHA-256 指纹。该密钥的有效性、余额未进行查询。

默认不读取旧 `DEEPSEEK_API_KEY`，也不自动加载 `.env`。只有同时设置新变量和显式开关，才可能发出外部生成请求；交接密钥即使被填入新变量也会被阻止。

如使用自己拥有且获授权的新密钥，在启动前设置终端变量：

```powershell
$env:GUIDE_ALLOW_REMOTE_LLM = 'true'
$env:GUIDE_LLM_API_KEY = Read-Host '输入你自己的新密钥'
python -X utf8 -S run.py
```

结束后关闭该终端，或移除这两个环境变量。不要把密钥写入代码或提交仓库。模型请求固定发到 DeepSeek HTTPS 地址，超时或引用编号异常会回退到本地资料。该可选路径已使用模拟响应验证，**未消耗真实额度验证在线生成质量**。

| 变量 | 默认值 | 用途 |
|---|---|---|
| GUIDE_ALLOW_REMOTE_LLM | false | 明确允许外部模型请求 |
| GUIDE_LLM_API_KEY | 空 | 自己的新密钥；交接密钥被拦截 |
| GUIDE_LLM_MODEL | deepseek-chat | DeepSeek 兼容模型名称 |
| GUIDE_DATA_DIR | 项目下 .runtime | 本地对话、清单与反馈数据库位置 |

界面与 `/api/health` 会显示当前模式。`remote_calls` 是该进程实际尝试的模型请求数，不等同供应商账单；本轮默认模式验收值为 0。

## 资料准确性

“采集日期”不等同“适用年份”。交接文件中含2024级资料和第三方建议，它们会带年份和可信度提醒；当前尚未核对2026级完整入学须知，程序不会承诺当年报到日期、接站时段、收费金额或设施开放时间。

官方服务入口、地址与咨询电话于2026-10-08对照[学校官网](https://www.hnvust.cn/)核对。其他继承资料标注“待核对”，而非已验证官方事实。地图对照原图修正了馨园、沁园混淆，使用图上位置，保留示意说明。

推荐为透明的本地规则匹配，不是大模型推理或录取概率。床位因子按示意位置主观赋值，不是实测噪音或采光；同分并列。社团与组织是高校常见示例，未确认本校实际开设；收藏不会代办报名或预订。竞赛A/B/C保留为原指南的参考标签，不代表教育部统一等级或本校认定。

修改知识资料后重启服务即可。可独立检查切分：

```powershell
python -X utf8 -S backend/scripts/ingest.py
```

## 项目与数据

```text
run.py                         单命令启动
backend/main.py                本地 HTTP API 与静态页面服务
backend/answer.py               本地证据回答 / 可选 DeepSeek 适配
backend/retriever/              中文检索、文本块和来源元数据
backend/catalog.py             FAQ、地图热点、路线、准备清单
backend/experience.py          偏好校验、规则推荐、统一目录与计划动作
frontend/decision.js           推荐、对比与收藏计划交互
frontend/planner.js            日程、任务、备份预览与日历下载
backend/planner.py             输入校验、备份格式及全天日历生成
backend/store.py               SQLite 保存对话、偏好、收藏、清单与会话隔离
backend/settings.py            外部调用开关与密钥指纹拦截
frontend/                      HTML、CSS、JavaScript 界面
config/blocked_key_fingerprints.json 交接密钥拒绝列表
docs/                          接手证据、验证、过程和交付文档
.runtime/                      运行数据，Git 忽略
```

本地服务只绑定127.0.0.1，拒绝陌生Host与跨站Origin，不是面向公网的多用户部署版本。会话标识由浏览器随机生成并保存，同浏览器的标签页共享记录。清除浏览器存储会失去原会话入口；导出记录可用于自行备份。清空对话保留清单。
