# 初到 · CampusMate 2.0.1 技术说明

## 1. 产品目标与范围

为河南科技职业大学新生提供从查资料到落实准备的路径。学生可先在问答核对来源，再到清单、准备台、地图和个人任务采取行动。第二所学校是空白接入模板。校园地图为示意，三维建筑不作为测绘或实地导航。

## 2. 架构与数据流

浏览器使用 HTML、CSS 和 JavaScript，通过同源 API 请求 Python 标准库服务。应用按学校加载知识清单与检索器，按学校分目录存储 SQLite 数据。业务模块分别处理问答、校园行程、报到演练、准备台、成长匹配和任务。Three.js 与 PixiJS 均在本地加载，分别服务三维校园和封面人物。

本地问答通过中文 BM25、关键词和意图规则选取证据，回答带来源、适用年份和引用编号。用户主动选择联网增强时，应用读取河职大公开公告索引，在本机匹配标题，并保留官网入口。访问遵守站点规则，按栏目缓存；失败时继续回答本地资料。此模式不调用外部生成模型。

## 3. 意图控制与迭代

用“目标、边界、验收”描述需求。免费检索要保留官网来源和本地回退；长卷要有透视和首尾衔接，还要保留平面阅读；问答使用可执行建议，但仍保留资料年份和适用范围。每次调整都检查对应的失效路径，完整原始对话和真实 Git 提交对应关系另见参赛证据索引及参赛者提供的导出。

## 4. 工程边界与可复现性

Python 3.10+ 即可启动，无需安装服务端第三方库、配置账号或下载模型。独立解压验收核对文件哈希、首页和首次答复，模拟官网不可达并检查本地回退，再检查清单在重启后仍可读取。验收不计 Python 安装和人工浏览器操作。

应用为本机运行原型。学校与会话隔离用于防止本机数据串用。默认不请求付费模型，提交包应排除密钥和真实个人运行数据库。若用于公网，需另行设计身份认证、访问控制和运维。采用的视觉素材和第三方库应在最终提交时核实来源与授权。

## 5. 评估与后续

固定 FAQ 的首条关键词覆盖用于检索回归，不能当作开放问答的正确率。功能测试和浏览器检查分开统计。后续用同一提交版验证低配手机、键盘可用性和放大字号，并收集新生完成报到材料、找地点和保存任务三类操作的试用反馈。
