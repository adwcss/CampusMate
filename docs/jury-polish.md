# 评审反馈与复验

预指导总分 70 分，反馈建议深化重点。本轮深化外地新生从问答到完成准备事项的流程。

1. 在河职大新生问答中点击外地新生体验题，展开交通与接站来源，核对参考届别。
2. 只选择证件与交通，保存并打开报到清单。在“我的出发准备事项”标为完成一项，进度应为 1 / 2。
3. 刷新页面，再回同一回答保存相同两项。应新增 0 项、已有 2 项，进度仍为 1 / 2。可重新标为待办。切换河科大后检查学校记录隔离。
4. 辅助展示可打开四人寝和六人寝 3D，点选床位、查看实拍对照或返回平面图。

## 第三轮新增复验

输入“开学得带啥？高铁下来有迎新车吗？”，应分别看到报到材料和交通建议，以及对应的两条引用与可选准备事项。再输入“2027级开学带啥、在哪接驳？”，应看到按 2027 级核对安排的建议。测试同时检查往届年份未出现在这条回答正文里。

系统先识别入学语境，再从材料、交通、出发前核对三类事项中匹配主题。至少匹配两类才生成分段回答。指定届别时走按年份筛选资料的路径。单事项、无关问题和第二所学校继续走各自原有资料流程。自检包含四种有效组合同义问法及三种边界用例。

## 运行包内自检

解压后进入 CampusMate 文件夹，双击“评审自检.cmd”。它会运行核心问答与准备事项验收，并在窗口显示结果。需先安装 Python 3.10 或以上。自检采用临时会话和数据库，官网不可达使用模拟响应，外部模型调用为零。

评委也可启动应用手动走上述路线。回答里的“查看报到清单”会在已有准备事项时直接定位到个人准备事项。知识来源和适用范围见 [两校入学资料核对](arrival-source-audit.md)。

Edge 实测通过全部清单操作。核心回归 82 项、双校回归 30 项及评审验收通过。现有 1080p 演示为 5 分 06.5 秒，含 2 分 35.5 秒协作回放，画面覆盖本轮之前的问答与清单流程。本轮新增完成状态以新版作品介绍截图及以上复验步骤为据。
