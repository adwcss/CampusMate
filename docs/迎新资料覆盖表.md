# 迎新资料覆盖表

这一页区分可直接操作的功能、参考资料和需要查看当届原文的事项。

| 新生事项 | 当前覆盖 | 使用方式 |
| --- | --- | --- |
| 报到材料 | 本地准备清单和材料参考 | 先准备录取通知书等，再与个人随录取材料对照 |
| 报到、接站、军训时间 | 本地历史流程与公开公告入口 | 用历史流程熟悉步骤，车票和行程按本届正式通知安排 |
| 收费与资助 | 本地政策和流程参考、官网入口 | 缴费前核对本届专业、金额及官方渠道 |
| 校园地点与宿舍 | 二维地图、风格化三维模型、宿舍照片参考 | 用于认识地点和整理偏好，实际位置和床位按现场安排 |
| 社团、学生组织、竞赛 | 参与建议、任务练习与来源入口 | 按兴趣先体验，再按当届招新或赛事公告办理 |
| 个人准备记录 | 清单、准备台、行程、收藏、日程 | 当前浏览器会话可继续，按需导出个人备份 |

待扩充优先顺序：当届报到须知 → 当届收费说明 → 当届接站安排。新增正文应记录学校官方 URL、发布日期、适用届别及内容校验信息。免费的官网模式只匹配已接入公开栏目的标题和入口。
