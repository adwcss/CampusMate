# CampusMate 单校版复现

本版面向河南科技职业大学。旧多校演示及当时的测试数据保留在代码历史中。

## 离线可以核对的功能

1. 运行 `python -X utf8 -S run.py`，打开 [本机入口](http://127.0.0.1:8765/)。
2. 进入新生问答，点击「体验：外地新生如何准备报到？」。展开接站来源，核对适用年份。
3. 只选证件和交通两项，保存、刷新，再提交相同两项。首次新增两项，重复提交新增零项。清单保留原进度。
4. 运行 `python -X utf8 -S tools/jury_check.py`。脚本使用隔离目录、测试会话和本机端口，检查单校入口、引文、保存、重启恢复及模拟官网故障。

## 真实 DeepSeek 联网案例

按项目 README 配置服务端 DeepSeek 凭据，选择「自动检索（本地优先）」。搜索与模型生成按服务条款计费。

| 问题 | 可核对的结果 |
| --- | --- |
| 华为 ICT 网络赛道都考哪些知识点？ | 显示联网回答，按来源区分赛季，展开编号可打开华为原文。 |
| 数学竞赛考哪方面的知识？ | 可核对全国大学生数学竞赛主办方通知中的不同组别考查范围。 |
| 河南科技职业大学的校园支付平台从哪里进入？ | 选择默认模式时可用已有本地证据，优先给出核对入口。 |

单校版演示的 4:21 起记录了华为 ICT 问答的真实网页操作。答案来源之一为[华为 ICT 大赛 2022–2023 中国区实践赛说明](https://e-campaign.huawei.com/minisite/cn/rcfz/ICT2022/practice.html)，可用于备赛参考。数学题曾实测返回[第十八届全国大学生数学竞赛主办方通知](https://www.cmathc.org.cn/tzgg/545.html)。外部服务结果可能随时间变化。

本地回归使用模拟响应覆盖无关结果重试、过期和无效引用处理、超时及本地证据缺口。运行快照的独立解压验收使用离线与模拟路径。
