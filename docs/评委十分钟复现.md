# 评委十分钟复现

适用于初到 CampusMate 2.0.1 工作区评审快照。需要 Python 3.10+ 和现代浏览器，核心功能无需安装 Python 第三方包或配置密钥。

| 时间建议 | 操作 | 验收结果 |
| --- | --- | --- |
| 0–2 分钟 | 解压评审运行快照，在 CampusMate 目录打开 PowerShell | 可看到 run.py、frontend、backend 和 SNAPSHOT.json |
| 2–3 分钟 | 运行 `python -X utf8 -S run.py`，打开 http://127.0.0.1:8765/ | 封面可跳过，进入校园长卷和工具台 |
| 3–5 分钟 | 在新生问答点击「体验：外地新生如何准备报到？」，展开交通与接站引用 | 材料、接站、出发前核对分段呈现，往年安排有年份，当前安排有核对入口 |
| 5–6 分钟 | 只选择证件和交通两项并保存，打开报到清单后刷新 | 两项出现在「我的出发准备事项」。重复保存时应跳过已有事项 |
| 6–8 分钟 | 在校园地图搜索图书馆，点选地点，再打开三维校园 | 二维可查看位置与说明，三维可旋转、缩放并查看建筑信息 |
| 8–10 分钟 | 看资料来源，按需运行自动验收 | 来源可核对，验收结果提供实测耗时 |

端口占用时，运行 `python -X utf8 -S run.py --port 8766` 并打开相应地址。停止服务按 Ctrl+C。

## 自动验收

```powershell
python -X utf8 -S tools/jury_check.py
```

该命令用独立数据库和自动分配的本机端口检查首页、首次带来源的问答、模拟官网不可达时的本地回退、清单持久化、二维和三维地图资源。不会调用付费模型，不会改动日常记录。计时范围从创建本地服务到健康检查及首次回答，人工解压和浏览器操作另计。

## 联网与版本说明

复现声明。本指南覆盖评审快照的安装、运行和核心体验验证。评审可按同一路径重新执行功能验收，联网公告结果随学校发布变化。开发演进由仓库提交记录、原始 AI 对话和协同录屏共同核验。

- 默认问答走本地知识库。选择「联网增强」时，尝试查公开的学校公告标题和入口，详情请打开官网原文。官网不可达时回退本地资料。可在启动前将 `CAMPUSMATE_ALLOW_SEARCH` 设为 `false` 禁用联网。
- `.env.example` 是变量说明，应用不自动加载它。评审无需复制密钥或提供原始会话数据。
- SNAPSHOT.json 的 SHA-256 用于校验本次运行文件。该快照是功能验收材料，代码仓库和演进记录由参赛者另行提交。
