## AI 助手 · 2026-11-08T10:59:20.914Z

有。**你现在的项目可以直接接 Brave Search 的免费额度，无需改代码。** 选择 **Search** 方案，每月有 **5 美元免费额度，约 1,000 次搜索**。开通需要验证信用卡，但可以把预充值设为 0。[Brave 官方额度说明](https://api-dashboard.search.brave.com/documentation/resources/help-feedback)

想只用免费额度，按这三步设置：

1. 在 Brave 后台选 **Search** 预付费方案，把 **Prepay amount** 设为 **$0**，关闭 **Auto-reload**。
2. 生成 **Search API Key**，用前面那组 PowerShell 命令配置并重启项目。
3. 在新生问答里选择 **联网增强**。免费额度用完、预付余额为 0 时，搜索会暂停，项目会回退到本地知识库。

如果你说的免费是指 **不绑卡、不申请密钥**，Brave 不符合这个要求。适合这个校园项目的替代做法是直接读取学校官网的公开公告，再与本地知识库一起检索。这个方案需要新增一个搜索入口，覆盖范围是接入的官网栏目。
